# 📊 Dataset Analyzer ML Platform

Flask-based machine learning and data analysis platform designed for automated dataset exploration, preprocessing, visualization, and model training.

---

## 🚀 Features

- Upload and analyze CSV datasets
- Automated dataset summary and statistics
- Missing value detection and preprocessing
- Feature normalization and label encoding
- Interactive data visualizations
- Machine learning model training
- Classification and regression support
- Model saving using Joblib

---

## 🛠 Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Machine Learning
- Data Visualization
